# Desweb — sitio web corporativo

Nueva web de Desweb, diseñada para presentar servicios digitales y productos de software propios.

## Stack
- React + Vite
- JavaScript
- CSS responsive sin dependencia de UI externa

## Desarrollo local
```bash
npm install
npm run dev
```

## Compilar para producción
```bash
npm run build
npm run preview
```

## Despliegue
La web actual de WordPress en https://desweb.cloud/ debe permanecer activa durante el desarrollo. Publicar esta versión en un entorno de pruebas/subdominio y cambiar el dominio principal solo después de validar contenido, SEO, formularios y analítica.

## Variables de entorno
La versión inicial no requiere variables de entorno ni secretos. No agregar claves privadas al repositorio.

## Contacto
Actualizar los datos comerciales, enlaces de productos y políticas antes del lanzamiento.
